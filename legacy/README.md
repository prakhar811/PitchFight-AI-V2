# Legacy V1 reference

This directory contains the PitchFight AI V1 implementation, moved here as a
migration reference for the V2 rebuild.

The canonical original V1 project remains in its separate repository and is
preserved there. This copy exists only so V2 work can consult V1 behavior
without depending on it.

**New V2 code must not import from `legacy/`.**

`legacy/` will eventually be removed once migration is complete.
